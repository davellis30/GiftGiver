# GiftGiver

A simple web app to keep track of gift ideas for your loved ones.

## Features

### Gift Tracker (`index.html`)
- Add gift ideas with name, recipient, price, and occasion
- Track gifts for different occasions (birthdays, holidays, etc.)
- Add notes to remember details about each gift
- Data persists in browser local storage

### Gift Suggester (`gift-suggester.html`)
- Enter your partner's last 5 purchases
- Set your budget for the gift
- Analyzes purchases to detect interests (fitness, cooking, music, tech, etc.)
- Generates new personalized gift ideas based on what they've bought
- Each suggestion explains why it's a good fit

## Usage

- Open `index.html` to track and manage gift ideas
- Open `gift-suggester.html` to get AI-powered gift suggestions based on purchase history
